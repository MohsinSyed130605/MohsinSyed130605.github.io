# Mohsin Syed — Developer Portfolio

[![Live Site](https://img.shields.io/badge/Live-mohsinsyed130605.github.io-f97316?style=for-the-badge&logo=githubpages&logoColor=white)](https://mohsinsyed130605.github.io)
[![License: MIT](https://img.shields.io/badge/License-MIT-amber?style=for-the-badge)](LICENSE)

A modern, high-performance personal developer portfolio built with a dark glassmorphism aesthetic, fluid typography, frameless portrait integration, and micro-interactions.

---

## ⚡ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Custom Design Tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React, Simple Icons
- **CI/CD & Hosting**: GitHub Actions & GitHub Pages / Cloudflare Pages

---

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/MohsinSyed130605/MohsinSyed130605.github.io.git
cd MohsinSyed130605.github.io
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
